# Application de gestion des urgences médicales

Projet académique : application mobile Flutter + API REST Spring Boot + MySQL.

| Module | Sujet |
|---|---|
| E1 | Profil patient |
| E2 | SOS et historique |
| E3 | Gestion des ambulances |
| E4 | Rendez-vous |
| E5 | Rappels de médicaments |
| E6 | Équipe et rapport d'ambulance |

Chaque module est développé sur sa propre branche puis intégré dans `main` par pull request.
